# Web Control Panel (`panel/`)

Полная документация по установке, multi-node, API и командам — в **[README.md](../README.md)** в корне репозитория.

Кратко:

```bash
# Вместе с VPN (рекомендуется)
sudo ./install_vless_manager.sh

# Только панель
sudo ./panel/install_panel.sh
```

Службы: `vless-panel.service`, `vless-agent.service` · порт **8765** · UI: **Control Panel**
