Настройки

{% include "csrf_input.html" %}

Создать: Cloudflare → My Profile → API Tokens → Create Token → «Edit zone DNS» (Zone Resources: Include → ваш домен).

Для xray-cf (VLESS+WS) достаточно Full — Cloudflare не валидирует origin-сертификат. «Full (Strict)» требует Origin Certificate от CF.

Подготовить домен через API

Создаёт A-запись (proxied), Origin Rule на порт origin и выставляет SSL-режим.
